## 🛠️ Projets GitHub principaux

### 📺 Secreto TV Shortcuts

Un lanceur de raccourcis léger conçu pour **Android TV & Google TV**.

Il permet d'accéder rapidement aux principaux paramètres du téléviseur, notamment le Wi-Fi, le Bluetooth, les applications, le stockage, l'accessibilité, les options pour les développeurs, l'installation d'applications provenant de sources inconnues et bien plus encore.

🌍 Multilingue : **English • العربية • Français • Español**

[Voir le projet](https://github.com/mohamedlalah/SecretoTVShortcuts) • [Dernière version](https://github.com/mohamedlalah/SecretoTVShortcuts/releases/latest)

## 🔬 En cours de développement

### 🖥️ Secreto TV Screen Test

Une application de test et de diagnostic d'écran conçue pour **Android TV & Google TV**.

Elle permet notamment de tester :

- Les pixels morts
- Le rétroéclairage
- Les couleurs
- Les dégradés
- L'overscan
- L'uniformité de l'écran
- Les informations d'affichage

Bientôt disponible dans l'écosystème **SecretoTools**.
